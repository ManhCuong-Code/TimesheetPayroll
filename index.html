Kiến Trúc Dữ Liệu & Stored Procedures

Cơ sở dữ liệu Microsoft SQL Server với chuẩn hóa phân ca và chấm công

Các Bảng Dữ Liệu Trọng Yếu
  • shift_assignments: Bảng phân công ca theo ngày Mới
  • work_shifts: Cấu hình cửa sổ sớm/muộn & ca qua đêm Nâng cấp
  • timesheets: Lưu trữ bản ghi chấm công (Unique đa ca) Chuẩn hóa
  • employee_face_profiles: Mẫu đặc trưng khuôn mặt AI Bảo mật
  • face_audit_logs: Nhật ký kiểm toán thiết bị sinh trắc Kiểm toán
5 Stored Procedures Chuyên Biệt
  • sp_GetAssignedShiftsForAttendance: Truy vấn các ca được phân công cho nhân viên quanh thời điểm chấm công.
  • sp_ResolveAttendanceShift: Phân giải ca làm việc tự động và tính điểm ưu tiên Check-in vs Check-out.
  • sp_ProcessFaceAttendance: Giao dịch SQL an toàn (UPDLOCK), tính giờ công, trừ nghỉ trưa và kiểm soát Cooldown 3 phút.
  • sp_GetAttendanceStatus: Kiểm tra trạng thái làm việc thực tế của nhân viên trong ngày.
  • sp_GetMonthlyAttendanceSummary: Tổng hợp dữ liệu công tháng phục vụ kế toán tính lương.

Hướng Dẫn Khởi Chạy Ứng Dụng

Các bước để vận hành hệ thống trên môi trường máy chủ và máy trạm Kiosk

1. Cơ sở dữ liệu SQL Server

Chạy tệp SQL migration đã chuẩn bị sẵn trên SQL Server:

sqlcmd -S .\SQLEXPRESS -d BangChamCongDB -i "Scripts\01_AutoFaceShift_Migration.sql"
  • Tự động mở rộng bảng work_shifts với cửa sổ sớm/muộn.
  • Tạo bảng shift_assignments và sinh dữ liệu phân ca mẫu.
  • Biên dịch 5 Stored Procedures phục vụ điểm danh tự động.
2. Ứng dụng Blazor Web Kiosk

Khởi chạy dự án bằng .NET SDK:

cd project\TimesheetPayroll dotnet build TimesheetPayroll.sln -c Release dotnet run --project TimesheetPayroll.Web
  • Mở trình duyệt: http://localhost:5050/face-checkin
  • Đưa khuôn mặt vào camera để chấm công tự động không cần bấm chọn ca.
  • Quản lý ca & phân ca tại: http://localhost:5050/admin/shifts
